# Progress Log

## 2026-09-27 (Phase 0 closed)

### Done
- Restored the URP 17.6.0, Input System 1.20.0 and Test Framework 1.8.0 packages that the committed manifest had lost. Stopped tracking `.dotnet-home/` and `.plastic/`. Git is now the source of truth (the old Plastic workspace `Rust+` no longer exists).
- Boot: `Assets/Scenes/Boot.unity` is the first build scene. It holds `GameBootstrapper` (session, simulation clock, telemetry, save validation) with `DebugOverlay`, a `Player` with `RuntimePlayerState`, a ground plane and a camera. The scene is generated by `RustPlus/Create Boot Scene`.
- One save path (`SavePaths`) and one default state (`SaveDefaults`) shared by the bootstrapper and the player.
- Save schema v2 with player / world / metadata sections; v1 files migrate automatically. The world seed is now `ulong` and the save tick is `long`.
- Saves never destroy data: unreadable or newer-version files are quarantined, the backup is used and restored, writes are flushed before the atomic replace, stale `.tmp` files are cleaned, and `Save` no longer mutates its input.
- Logger entries carry a UTC timestamp and tick, with a global minimum severity. `LogReceived` fires after the sink and isolates throwing subscribers.
- Local telemetry: one JSON Lines file per session under `persistentDataPath/telemetry/`.
- Debug overlay replaces the broken `TextMesh` debug console.
- Folders `Gameplay`, `World`, `Systems`, `UI`, `Data` exist with READMEs. The `RustPlus.UI` assembly holds presentation code.
- Tests split by subject; test asmdefs use `UNITY_INCLUDE_TESTS` and `nunit.framework.dll`; the PlayMode test no longer reflects on private fields.
- CI workflow `.github/workflows/tests.yml` (game-ci) for EditMode and PlayMode.
